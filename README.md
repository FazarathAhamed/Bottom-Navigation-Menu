# Bottom Navigation Menu

A simple, responsive bottom navigation bar built with **HTML, CSS, and vanilla JavaScript** — the kind of mobile-app-style nav you see at the bottom of apps like Instagram or Spotify, with **Home**, **Search**, **Favorites**, and **Profile** tabs and an active-state indicator.

## Features

- Fixed bottom navigation bar with icon + label buttons
- Active/selected tab highlighting (Home is active by default)
- Click-to-switch active state between tabs
- No frameworks or dependencies — pure HTML/CSS/JS
- Lightweight, easy to read, and easy to extend

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

## Project Structure

```
Bottom-Navigation-Menu/
├── index.html     # Page structure + nav markup
├── styles.css      # Styling for layout, icons, and active state
└── script.js       # Handles switching the active tab on click
```

## Getting Started

No build tools or installs required.

1. Clone the repo:
   ```bash
   git clone https://github.com/FazarathAhamed/Bottom-Navigation-Menu.git
   ```
2. Open `index.html` in your browser.
