# Top-Down Car Dodger

**Top-Down Car Dodger** is a fast-paced browser game built using **HTML, CSS, and JavaScript**.  
The objective is simple: **dodge incoming cars and survive as long as possible** while the game speed gradually increases.

---

## 🎮 How to Play

- **Desktop:** Use the arrow keys (← →) or **A / D** to move left and right. Press **Space** or click **Start** to begin.  
- **Mobile:** Use the on-screen ◀ and ▶ buttons to move. Tap **Start** to begin.  

**Goal:** Avoid all obstacles and get the highest score you can!

## 🧩 Features

- Smooth top-down gameplay
- Responsive design for both desktop and mobile
- Increasing difficulty over time
- On-screen touch controls
- Optional sound effects using Web Audio API
- Restart and mute buttons

---

## 🛠️ Technologies Used

- **HTML5 Canvas** — for rendering the game  
- **CSS3** — for styling and layout  
- **Vanilla JavaScript** — for game logic and animations  
- **Web Audio API** — for basic sound effects
